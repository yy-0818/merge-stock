🚀 立即使用

  1. 在 Excel 子表中添加"年份"列（任意位置）
  2. 填入年份数值（如 2024, 2025）
  3. 运行合并工具：
     • GUI: python3 gui.py
     • CLI: python3 merge_stock_files.py --src <源> --index <索引> --out <输出>
